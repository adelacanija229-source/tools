스케치업 자동 레이어 분류 (Auto Layer)
====================================================

객체 이름에 들어있는 키워드를 보고 레이어(태그)를 만들어 자동으로 배치합니다.

[설치]
1. 윈도우 탐색기 주소창에 아래 경로를 붙여넣고 이동합니다.
   %AppData%\SketchUp\SketchUp 2026\SketchUp\Plugins
   (2026 부분은 사용 중인 버전에 맞게 바꾸세요)

2. 이 zip 안의 아래 두 가지를 그 폴더에 "통째로" 넣습니다.
   - auto_layer.rb        (파일)
   - auto_layer           (폴더, 아이콘이 들어있음)

   ※ 두 개가 같은 위치에 나란히 있어야 툴바 아이콘이 나옵니다.

3. 스케치업을 껐다가 다시 켭니다.

[사용법]
- 툴바
  상단에 아이콘 2개가 나타납니다.
    레이어 아이콘 : 지금 분류 실행
    목록 아이콘   : 키워드 표 보기
  안 보이면 [보기] > [도구 모음] > "자동 레이어 분류" 를 켜주세요.

- 메뉴
  [확장 프로그램] > [자동 레이어 분류]

- 우클릭
  객체를 선택하고 우클릭 > [선택 객체 자동 레이어 분류]

[동작 방식]
- 객체를 선택하고 실행하면 선택한 것만, 아무것도 선택하지 않으면 모델 전체를 훑습니다.
- 컴포넌트와 그룹을 모두 처리하며, 중첩된 그룹 안까지 들어갑니다.
- 이름에 키워드가 없는 객체는 건드리지 않고 건너뜁니다.

[키워드 바꾸기]
auto_layer.rb 를 메모장으로 열어 위쪽 LAYER_MAP 을 고치면 됩니다.

  '벽'   => 'Layer_벽',
  'Wall' => 'Layer_벽',

왼쪽이 객체 이름에서 찾을 키워드, 오른쪽이 보낼 레이어 이름입니다.
