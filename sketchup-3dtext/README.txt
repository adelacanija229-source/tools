스케치업 3D 텍스트 편집기 (Editable 3D Text)
====================================================

[설치]
1. 이 zip 안의 editable_3d_text.rb 파일을 복사합니다.
2. 윈도우 탐색기 주소창에 아래 경로를 붙여넣고 이동합니다.
   %AppData%\SketchUp\SketchUp 2026\SketchUp\Plugins
   (2026 부분은 사용 중인 버전에 맞게 바꾸세요)
3. 그 폴더에 rb 파일을 붙여넣습니다.
4. 스케치업을 껐다가 다시 켭니다.

[사용법]
- 새로 만들기
  상단 메뉴 [확장 프로그램] > [3D 텍스트 편집기] > [새 3D 텍스트 생성]

- 수정하기
  만들어 둔 3D 텍스트 그룹을 선택하고 우클릭 > [3D 텍스트 수정하기]
  또는 [확장 프로그램] > [3D 텍스트 편집기] > [선택한 3D 텍스트 수정]

- 기존 텍스트 등록
  이 플러그인으로 만들지 않은 일반 3D 텍스트도
  [기존 일반 3D 텍스트 등록] 으로 편집 대상에 넣을 수 있습니다.

[특징]
- 문구, 글꼴, 크기, 돌출 두께를 나중에 몇 번이든 다시 고칠 수 있습니다.
- 수정해도 배치해 둔 위치와 회전각이 그대로 유지됩니다.
- 단위는 mm 로 입력합니다.
