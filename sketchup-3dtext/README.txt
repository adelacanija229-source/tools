스케치업 3D 텍스트 편집기 (Editable 3D Text)
====================================================

[설치]
1. 윈도우 탐색기 주소창에 아래 경로를 붙여넣고 이동합니다.
   %AppData%\SketchUp\SketchUp 2026\SketchUp\Plugins
   (2026 부분은 사용 중인 버전에 맞게 바꾸세요)

2. 이 zip 안의 아래 두 가지를 그 폴더에 "통째로" 넣습니다.
   - editable_3d_text.rb        (파일)
   - editable_3d_text           (폴더, 아이콘이 들어있음)

   ※ 두 개가 같은 위치에 나란히 있어야 툴바 아이콘이 나옵니다.

3. 스케치업을 껐다가 다시 켭니다.

[사용법]
- 툴바
  상단에 아이콘 2개가 나타납니다.
    A  아이콘 : 새 3D 텍스트 생성
    연필 아이콘 : 선택한 3D 텍스트 수정
  안 보이면 [보기] > [도구 모음] > "3D 텍스트 편집기" 를 켜주세요.

- 메뉴
  [확장 프로그램] > [3D 텍스트 편집기]

- 우클릭
  만들어 둔 3D 텍스트 그룹을 선택하고 우클릭 > [3D 텍스트 수정하기]

- 기존 텍스트 등록
  이 플러그인으로 만들지 않은 일반 3D 텍스트도
  [기존 일반 3D 텍스트 등록] 으로 편집 대상에 넣을 수 있습니다.

[특징]
- 문구, 글꼴, 크기, 돌출 두께를 나중에 몇 번이든 다시 고칠 수 있습니다.
- 수정해도 배치해 둔 위치와 회전각이 그대로 유지됩니다.
- 단위는 mm 로 입력합니다.
