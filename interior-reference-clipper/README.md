# Interior Reference Clipper

디자인 보드 작업 전에 자재 레퍼런스를 모아두기 위한 크롬 확장 프로그램입니다.
현재 페이지에서 제품 제목, 링크, 대표 이미지, 일부 상세 정보를 읽어와 사이드 패널 라이브러리에 저장합니다.

## 현재 기능

- 현재 페이지 클립
- 대표 이미지 자동 캡처 우선 저장
- 이미지 후보 선택
- 제목 후보 선택
- 제목 복사
- 링크 복사
- 이미지 저장
- 클립 검색
- 메모 저장
- 시리즈 / 제품명 / 상세 라인 일부 저장

## 설치

1. 이 폴더(또는 배포용 zip)를 내려받아 압축을 풉니다.
2. 크롬에서 `chrome://extensions` 를 엽니다.
3. 오른쪽 위 `개발자 모드`를 켭니다.
4. `압축해제된 확장 프로그램을 로드합니다`를 클릭합니다.
5. 압축을 푼 폴더를 선택합니다.
6. 확장 아이콘을 클릭하면 오른쪽 사이드 패널로 열립니다.

## 사용 흐름

1. 제품 페이지를 연 상태에서 사이드 패널을 엽니다.
2. `현재 페이지 클립`을 눌러 저장합니다.
3. 필요하면 제목 후보나 이미지 후보를 선택해 보정합니다.
4. 메모를 남기고, 나중에 제목 복사 / 링크 복사 / 이미지 저장으로 활용합니다.

## 참고

- 같은 URL은 중복 저장하지 않습니다.
- 저장 데이터는 `chrome.storage.local` 에 보관됩니다. (서버 전송 없음)
- `전체 비우기`를 누르지 않으면 클립은 계속 누적됩니다.
- 사이트 구조에 따라 제품명이나 상세정보는 일부 보정이 필요할 수 있습니다.
